## Result

Simplified the `03_medium_5k` CUDA implementation files:

- `code.cu`: removed `check_cuda`, CUDA event timing, `run_cuda`, debug `print`, and unused includes. Kept the direct one-thread-per-output kernel.
- `code2.cu`: removed host-side checks, unused event variables, debug `print`, and unused includes. Kept the `16 x 16` shared-memory tiled kernel.
- `code3.cu`: removed host-side checks, unused event variables, debug `print`, and unused includes. Kept the `32 x 32` shared-memory tile with per-thread `2 x 2` output, and fixed the final boundary stores so `row + 1` and `col + 1` are checked separately.
- `code4.cu`: removed padding kernels, low-architecture fallback, kernel-mode tracking, CUDA event timing, and host-side checks. The file is now a compact FP64 WMMA implementation for the fixed aligned `4096 x 4096 x 4096` case on `sm_80`.
- `build.sh`: changed all four builds to compile with `-arch=sm_80`, matching the current A800 hardware and the simplified WMMA implementation.
- `Readme.md` and `AGENT.md`: updated WMMA/build notes so they no longer claim `03_medium_5k/code4.cu` has padding or low-architecture fallback.
